# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-09-29

First public release.

### Added
- Core loop: customers arrive by ship, order through thought bubbles, get served and tip in Star Coins.
- Six recipes across three ingredients: coffee, stardust and nebula milk.
- Stations: coffee machine, stardust grinder, a purchasable Nebula Milk Steamer and a bin for zen do-overs.
- Customers: alien traveler, lost astronaut and hovering robot, each grooving to the music.
- Click-based Build Mode on a 1 m grid: buy, move, rotate, paint and store decorations; recolor the deck, rim and kiosk.
- Seven catalog items with live 3D thumbnails.
- Interactive radio with three original lo-fi tracks and sixteen sound effects.
- Title menu, pause menu and options (audio, language, video, controls).
- Localization in six languages: English, Portuguese, Russian, Korean, Simplified Chinese and Japanese.
- JSON autosave.
- Windows installer (Inno Setup), trailer and a static download page.
